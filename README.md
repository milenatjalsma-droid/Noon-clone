# Noon Clone – AI Recruiter

Een autonome AI-recruiter die vacatures omzet in een gerankte shortlist + gepersonaliseerde outreach.

## Functies
- Vacaturetekst analyseren → skills & criteria extraheren
- Kandidaten zoeken (GitHub API + slimme generatie)
- Automatisch ranken met score en redenen
- Gepersonaliseerde outreach berichten (verschillende tones)
- Export naar CSV
- Mooie web-interface

## Lokaal draaien
```bash
cd noon-clone
pip install -r requirements.txt
streamlit run app.py
```

Open daarna http://localhost:8501

## Cloud (gratis, voor jou + partner)
1. Maak een gratis GitHub account (als je die nog niet hebt)
2. Upload deze map als nieuw public repository
3. Ga naar https://share.streamlit.io
4. Log in met GitHub → Create app → kies dit repository → Deploy
5. Deel de link met je partner

De app is direct bruikbaar zonder API-keys.
